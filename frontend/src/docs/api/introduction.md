# 简介

欢迎使用 Pan API 文档系统！

## 什么是 Pan API？

Pan API 是一个统一的 AI 模型调用平台，旨在为开发者提供简单、高效、可靠的 AI 模型访问服务。

## 核心特性

### 统一接口
- 一个 API Key 访问所有模型
- 标准化的请求和响应格式
- 简化的集成流程

### 智能路由
- 自动选择最优模型
- 智能负载均衡
- 故障自动切换

### 精确计费
- 按 token 精确计费
- 实时用量监控
- 详细的账单记录

### 高可用性
- 多服务商容错机制
- 99.9% SLA 保证
- 全球节点部署

## 适用场景

- **聊天机器人**：构建智能对话系统
- **内容生成**：自动生成文章、摘要等
- **代码助手**：代码补全、生成、解释
- **数据分析**：文本分析、情感识别等
- **翻译服务**：多语言实时翻译

## 技术栈

- **后端**：Spring Boot + MyBatis
- **前端**：React + TypeScript + Tailwind CSS
- **数据库**：MySQL
- **部署**：Docker + Kubernetes
